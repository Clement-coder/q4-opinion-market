# Q4 Landing Page

A modern landing page for Q4, built with React and Vite. The project showcases a dark, premium marketing design with a hero section, prediction card, feature grid, and conversion-focused CTA sections.

## Tech Stack

- React 19
- Vite 7
- Tailwind CSS 4
- JavaScript

## Features

- Responsive landing page layout
- Interactive prediction card with YES / NO selection
- Modular React component structure
- Dark luxury visual design
- Mobile-friendly navigation

## Project Structure

```bash
src/
├── App.jsx
├── main.jsx
├── index.css
├── components/
│   ├── Header.jsx
│   ├── Footer.jsx
│   ├── FeatureCard.jsx
│   ├── QuestionCard.jsx
│   └── icons.jsx
```

## Prerequisites

- Node.js 18+
- npm

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production Build

```bash
npm run build
```

The generated production files will be placed in the `dist/` directory.

## Notes

- The `/login` and `/signup` links are placeholders for future authentication pages.
- The project is structured for easy scaling if more landing page sections or reusable UI components are added later.
